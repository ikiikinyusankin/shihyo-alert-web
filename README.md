# 指標アラート（iPhone向けWebアプリ版）

FXの経済指標について、本日の一覧を表示し、指定した指標の発表前にアラートを鳴らすWebアプリです。GitHub に置いて、iPhone のホーム画面から開いて使います。

- 取得元: Forex Factory／GMO外貨（画面のボタンで切り替え）
- データの取得: **毎朝6時ごろに1回**、GitHub 側で自動取得します（iPhone からは取得元に直接アクセスできないため）
- 表示: 日本語

---

## 1. GitHub に公開する手順

パソコンのブラウザで行います。所要時間は10分ほどです。

### 1) リポジトリを作る

1. https://github.com/ にログインし、右上の「＋」→「New repository」を選びます。
2. 「Repository name」に名前を入れます（例: `shihyo-alert`）。この名前が URL の一部になります。
3. 「Public」を選びます（無料プランでは、Public でないとページを公開できません）。
4. 「Add a README file」に**チェックを入れて**、「Create repository」を押します。

### 2) 公開方法を「GitHub Actions」にする

1. 作ったリポジトリの「Settings」→ 左の「Pages」を開きます。
2. 「Build and deployment」の「Source」を **「GitHub Actions」** に変更します。

### 3) ファイルをアップロードする

1. リポジトリの「Code」タブで「Add file」→「Upload files」を選びます。
2. この zip を展開したフォルダ `shihyo-alert-web` を開き、**中身をすべて選択して**（`.github` フォルダも含めます）、ブラウザの画面にドラッグします。
3. 画面下の「Commit changes」を押します。

`.github` フォルダが見えない・アップロードされない場合は、「Add file」→「Create new file」でファイル名に `.github/workflows/update.yml` と入力し、同名ファイルの中身を貼り付けて保存してください。

### 4) 公開されたか確認する

1. 「Actions」タブを開くと、「データ取得と公開」が動いています。緑のチェックが付けば完了です（1〜2分）。
2. 「Settings」→「Pages」に表示される URL（`https://（ユーザー名）.github.io/（リポジトリ名）/`）を開きます。

「Actions」に何も表示されない、または赤い×が付いた場合は、「Actions」→ 左の「データ取得と公開」→「Run workflow」を押してやり直してください。

### 5) iPhone のホーム画面に追加する

1. iPhone の **Safari** で上の URL を開きます。
2. 共有ボタン（四角から矢印が出ているボタン）→「ホーム画面に追加」を選びます。
3. ホーム画面のアイコンから開くと、アプリのように全画面で表示されます。

---

## 2. 使い方

- **取得元**: 見出しの下のボタンで Forex Factory / GMO外貨 を切り替えます。
- **注目**: 行の左のチェックを入れると、その行が黄色の枠になります。重要度「高」は最初からチェックが入ります。
- **アラート**: 行の右のスイッチを ON にします。何分前に鳴らすかは「鳴らすタイミング」で選びます。
- **アラート待機を始める**: アプリを開いたら、最初にこのボタンを押してください。押すまでは音が鳴りません（iPhone のブラウザの決まりです）。
- **画面を消さない**: 待機中は画面が自動で消えないようにします（iOS 18.4 以降のホーム画面アプリで有効）。
- **カレンダーに登録**: ON にした指標を iPhone のカレンダーに登録します。アプリを閉じていても、カレンダーの通知で知らせます。
- **再読み込み**: 最新のデータを読み直します（取得元から取り直すわけではありません。取得は毎朝1回です）。
- 設定（ON・注目・タイミング・音）は、その端末のブラウザ内に保存されます。

---

## 3. iPhone で使うときの制限

- アラートが鳴るのは、**アプリを開いて表示している間だけ**です。アプリを閉じる、別のアプリに切り替える、画面をロックする、のいずれでも止まります。確実に知りたい指標は、カレンダーに登録してください。
- カレンダーの通知は iPhone 標準の音で1回だけ鳴ります。音声ファイルや繰り返しは使えません。
- カレンダー登録のあとにアラートを OFF にしても、カレンダー側の予定は消えません（カレンダーアプリで削除します）。
- 音が出ないときは、音量と、本体横の消音スイッチ（またはコントロールセンターの消音モード）を確認してください。
- 音声ファイルは選び直しが必要になることがあります（ブラウザのデータを消した場合など）。

---

## 4. 注意

- **このページは、URL を知っていれば誰でも開けます。** 指標データもそのまま置かれます。Forex Factory の利用規約はカレンダーデータの複製・再配布を禁止しているため、URL を他の人に共有しないでください。検索エンジンに載りにくくする設定（noindex）は入れてありますが、非公開にはなりません。
- GMO外貨には公式のデータ提供の仕組みがなく、ウェブページの表を読み取っています。ページの作りが変わると取得できなくなります（その場合は `lib/gmo.js` の修正が必要です）。
- GitHub の自動実行は、混雑時に開始が数分〜数十分遅れることがあります。
- リポジトリに長期間まったく動きがないと、GitHub が自動実行を止めることがあります。このアプリは毎朝データを保存するので通常は止まりませんが、止まっていた場合は「Actions」タブに出る「Enable workflow」を押してください。
- 取得に失敗した取得元は、前回のデータを残したうえで、画面にその旨を表示します。両方とも失敗した日は、GitHub から失敗の通知メールが届きます。

### 取得する時刻や回数を変える

`.github/workflows/update.yml` の `cron: '7 21 * * *'` を書き換えます。時刻は協定世界時（日本時間 −9時間）で書きます。

- 毎朝 6:07（現在の設定）: `7 21 * * *`
- 朝・昼・夕の3回（6:07 / 12:07 / 18:07）: `7 21,3,9 * * *`

### 公開をやめる

リポジトリの「Settings」→ 一番下の「Delete this repository」で削除すると、ページも見られなくなります。

---

## 5. ファイル構成

```
.github/workflows/update.yml   毎朝の取得と公開の設定
scripts/fetch.js               取得して docs/data/data.json を作る
lib/                           取得元ごとの読み取り処理、日本語化
data/translations.json         指標名の対訳表（表にない指標名は英語のまま表示）
docs/                          公開されるページ（index.html / style.css / app.js / アイコン / データ）
```
